Professional Cash Management for Odoo 19

Version 19.0.1.0.0 • Odoo 19 • LGPL-3

📋 About This Module

Cash Journal is a complete and professional ERP solution for integrated cash flow management. Designed to work seamlessly with Odoo, this module offers an intuitive daily workflow, detailed reports, and robust financial traceability.

Whether you manage a restaurant, retail store, or service business, Cash Journal simplifies cash control while ensuring regulatory compliance and data security.

✨ Key Features

📊 Monthly Reports

  • Automatic sequential numbering
  • Smart initial balance (inherited)
  • Automatic final balance calculation
  • Protection against modifications

📝 Daily Operations

  • Inflows and outflows simply signed
  • Description and beneficiary
  • Automatic classification
  • Locking after closure

🔄 Integrated Workflow

  • Open daily cash register
  • Record operations
  • Close daily cash register
  • Close monthly report

📑 Analytical Operations

  • Complete operations list view
  • Filtering by type and status
  • Bar chart analytics
  • Total visualization by report

📊 Professional Reports

  • Excel export with formatting
  • Professional PDF report
  • Company brand colors
  • Automatic summaries

🔒 Security & Control

  • Two user roles
  • Granular permissions
  • Complete audit trail
  • Data protection

Data Models

Model Description Key Fields

cash.journal.operation Daily operation Date, Description, Amount, Beneficiary, Locking
